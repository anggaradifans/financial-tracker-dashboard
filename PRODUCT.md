# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
People managing their personal finances. Administrators monitor the shared database capacity.

## Product Purpose
Track transactions, budgets, goals, savings and net worth in one dashboard.

## Capabilities and Constraints
React and Supabase application. The current database uses the Free plan with a 500 MB allowance. The admin storage page must enforce authorization in the database, monitor capacity and growth, show table sizes and alerts, and support lossless downloads first. External archiving is a future option. Never delete transactions as part of a download.

## Brand Commitments
Extend the existing Financial Tracker interface and navigation.
